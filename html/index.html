3/27/26: I started this project ~3 months ago in January, since I developed an interest in embedded systems and low-level programming. This was my first real exposure to programming on an MCU bare-metal, with operating system to abstract away the hardware.

I wanted to do an MP3 player because I enjoy listening to music while walking, working, relaxing. I also wanted a low-power solution rather than just listening to music with my smartphone device. It's a project that I feel I have a lot of interest in, and it also doesn't seem too complicated for a beginner project (at the bare minimum atleast), and can be expanded upon with new features.

The first couple of weeks were spent reading and understanding the basics of bare-metal programming, and just getting a gist of everything in this new environment. I read articles, books. watched videos and courses to answer some fundamental questions; {What is an embedded system?, What is a microcontroller?, What is bare-metal vs RTOS?, etc}.

Then the next few were spent exploring the peripherals, and incrementally building the subsystems from the ground up. I blinked an LED, then I faded the LED. I printed some text to my PC terminal via UART, then I implemented printf debugging. I read datasheets and specifications on my external components. Then I talked to them via SPI and I2C.

As I worked along these past 3 months, I learned to appreciate how things worked under the hood, but also why abstraction exists as well. I never thought that I'd have to implement my own system calls, create a graphics API, or even integrate a file system driver. Because I'm so used to the general-purpose computer providing these services for me already, I never had to think about them.

As of writing, the project isn't finished yet. I've implemented a file system, display, and button controls, but I still need to implement audio playback. But the point is: I've learned quite a lot from working on this project and will continue updating this blurb. This probably isn't enough to land an entry level job yet in the embedded systems field, seems like most companies want experience for an entry-level role, so I'll keep working on projects after this one. I intend to tackle a problem that would involve an RTOS, and maybe include IOT and high-speed protocols like USB, BLE, or Ethernet.
